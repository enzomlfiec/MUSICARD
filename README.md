Um projeto desenvolvido em **React JS** para aula inversa da FIEC sobre React Router.

## 🛠️ Tecnologias
- React
- JavaScript
- Tailwind CSS
- React Router
- Vite
- Lucide React

## 🚀 Como instalar e executar
```bash
git clone https://github.com/enzomlfiec/MUSICARD.git
npm install
npm run dev
```

Para um sistema com rotas FUNCIONANDO use os seguinte comandos:

```bash
git clone https://github.com/enzomlfiec/MUSICARD.git
git switch routed
npm install
npm install react-router-dom
npm run dev
```
